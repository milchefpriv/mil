# Réseau 360°

Mini-site statique publié en parallèle de MIL dans le dossier `reseau-360` du dépôt.

## Adresse publique

https://milchefpriv.github.io/mil/reseau-360/

## Fichiers

- `index.html` : contenu de la page
- `styles.css` : design responsive et version mobile
- `script.js` : curseur du montant, choix du taux et calcul de la commission

La page principale de MIL reste indépendante et n'est pas modifiée par ce mini-site.

Toute mise à jour de ces fichiers sur la branche `main` est automatiquement republiée
par GitHub Pages.
